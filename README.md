# 🛍️ 살래팔래 (Salle-Palle)
> **"누군가의 기억이 나에게 새로움이 되는 순간,"** <br>
> 자체 페이 결제 시스템 기반의 지역 밀착형 중고거래 & 나눔 플랫폼

<br>

## 1. 💡 프로젝트 개요 (Overview)

### 🎯 기획 배경 및 목적
당근마켓의 '지역 기반 거래'와 인스타그램의 '피드형 소통'을 모티브로 기획한 중고거래 웹 서비스입니다. 기존 직거래 방식의 불편함을 해소하고자 **'살래 포인트'와 '팔래 마일리지'라는 자체 페이 시스템을 구축**하여 플랫폼 내에서 안전하고 간편한 제화 거래가 이루어지도록 설계했습니다. 단순 판매를 넘어 '나눔' 문화를 장려하는 마일리지 보상 시스템을 도입한 것이 특징입니다.

<br>

## 2. 💸 비즈니스 모델 (Business Model)
본 프로젝트의 핵심은 **금융결제원 오픈 API**를 연동한 자체 페이 에코시스템입니다.
- **살래 포인트:** 물품 구매를 위한 기본 재화. 일반 회원은 카드 및 계좌이체 등 다양한 방법을 통해 포인트를 충전/구입하여 거래에 사용합니다.
- **포인트 환전:** 판매 권한이 있는 회원은 물품 판매로 얻은 '살래 포인트'를 실제 현금으로 환전할 수 있습니다.
- **팔래 마일리지 (리워드 시스템):**
  - 포인트 충전 시 결제 금액의 10%를 마일리지로 적립
  - 판매자가 '나눔 게시판'을 통해 무료 나눔 완료 시 2,000 마일리지 지급
  - 적립된 마일리지는 물품 구매 시 현금(포인트)처럼 사용 가능

<br>

## 3. 🛠 기술 스택 (Tech Stack)

**Backend**
- `Java 8` `Spring Web Security`
- **Components:** `FileComponent` (파일 입출력 처리), `MailSender` (이메일 인증)

**Frontend**
- `JavaScript` `jQuery` `AJAX` `JSP` `HTML/CSS`

**Database & Tools**
- `MySQL` `STS4 (v5.0.7)`

**External APIs**
- `금융결제원 오픈 API` : 포인트 충전 및 환전 핀테크 연동
- `Kakao Map / Local API` : 지역(예: 양산시 등) 카테고리화 및 위치 기반 주소 찾기
- `Naver Login API` : 소셜 로그인 연동

<br>

## 4. 🏗 시스템 아키텍처 (Architecture)
- **디자인 패턴:** 철저한 **Spring MVC 패턴**(View > Controller > Service > DAO > Database) 준수로 비즈니스 로직과 프레젠테이션 계층 분리
- **보안/인증:** Spring Web Security 설정(`config`, `UserDetail`, `LoginSuccess`, `LoginFail` 핸들러 등)을 통한 체계적인 권한 제어

<br>

## 5. 📌 핵심 기능 (Core Features)

### 👤 1. 회원 및 권한 관리 (Spring Security)
- **이메일 인증 기반 가입:** `MailSender`를 활용하여 이메일 인증번호 확인 후 최종 가입 승인 처리
- **지역 기반 카테고리:** 카카오 API를 활용해 '시' 단위(예: 양산시) 주소를 자동 분류하고 상세 주소 입력
- **엄격한 권한 분리 (일반/판매자/관리자):** 기본 가입자는 '일반 회원'이며, 관리자(Admin)의 승인을 받아야만 '판매 권한'을 획득하여 게시글을 등록할 수 있도록 구현

### 🛒 2. 중고 물품 거래 게시판
- 판매 권한 보유자 전용 상품 등록
- 자체 재화인 '살래 포인트' 및 '팔래 마일리지'를 복합적으로 사용한 상품 구매 로직 구현
- 판매 수량 설정(재고 관리) 기능 및 판매자 추천 시스템 도입

### 🛡️ 3. 실시간 채팅 및 자체 AI 보안 시스템 '살래가드(Salle-Guard)' 구축
- **웹소켓(STOMP) 기반 실시간 통신:** 1:1 채팅, 실시간 읽음 처리 및 알림 기능 구현
- **스마트 안전결제 필터링:** OpenAI API를 활용해 단순 금지어를 넘어 직거래 및 외부 채널 유도 뉘앙스까지 실시간으로 판별하고 경고하는 전용 보안 시스템 '살래가드' 적용
- **관리자 모니터링 및 Soft Delete 적용:** '살래가드'가 위험으로 분류한 채팅방을 관리자 대시보드 최상단에 노출. 관리자 강제 해산 시, 일반 유저 화면에서는 삭제되나 DB에는 증거로 보존(Soft Delete)되도록 설계하여 사후 대처 강화

### 👑 4. 통합 관리자 대시보드 및 서비스 모니터링 (Admin System)
- **AJAX 기반 실시간 통계 대시보드:** 관리자 메인 화면 접속 시, 비동기 통신(AJAX)을 활용하여 5초 주기로 '신규 판매자 승인 대기 수' 및 '전체 회원 수' 등의 핵심 지표를 새로고침 없이 실시간 자동 갱신
- **체계적인 회원 및 권한 관리:** 일반 회원의 '판매자 권한 신청' 내역을 검토하여 승인/반려 처리하며, 악성 유저에 대한 계정 정지 및 강제 탈퇴 기능 구현
- **플랫폼 모니터링 및 제재 시스템:** 등록된 전체 중고 물품을 조회 및 관리하고, 자체 보안 시스템 '살래가드'와 연동하여 위험 감지된 채팅방을 관리자 리스트 최상단에 붉은색 뱃지로 시각화하여 즉각적인 사기 대응 환경 구축
